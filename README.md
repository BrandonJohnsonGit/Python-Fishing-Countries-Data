# Python-Fishing-Countries-Data

In this project the goal was to make two different models, a regressor and a classifier, and to predict different aspects of the fishing expeditions. I worked with data from multiple different countries and had to re-organize the data several times. First was a Linear Regression Model, and then made a Naive Bayes Classifier. With the Linear Regression model there was a target of EffActive, and for the Naive Bayes Classifier there was a target of the Countries. I was able to make two different but positive models. The Linear Regression Model allowed for me to acknowledge that the predictors had a decent chance of affecting EffActive when one considers how many variables/columns were in the data set. The Naive Bayes Classifier allowed me to understand the probabilities of the predictors based on the target. Overall, both of the models worked well.

It is worth noting that the project is intended to be used in Jupyter Lab.
